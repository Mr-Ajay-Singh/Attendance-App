# Android Biometric Attendance App

A modern, production-grade Android attendance verification application featuring on-device AI face recognition, high-precision GPS tracking, interactive map visualization, offline-first Room persistence, and live cloud backend synchronization.

Built using **Kotlin**, **Jetpack Compose (Material 3)**, **Clean Architecture**, **Google Play Services TFLite (MobileFaceNet)**, and a **Live Node.js / MongoDB Atlas Backend**.

---

## 📋 Assignment Requirements & Scope Overview

| Feature Area | Assignment Requirement (In-Scope) | Value-Added Production Implementation (Beyond Requirements) |
| :--- | :--- | :--- |
| **Authentication** | Simple Login screen with dummy credentials for Admin & Staff. | **Live JWT Authentication** with role-based routing (Admin vs Staff), session persistence via Encrypted Token Store, and a Master Admin Bootstrap flow. |
| **Staff Management** | Admin views staff list, adds new staff (Name, Employee ID), opens profile. | Searchable staff directory, autogenerated temporary credentials with one-tap clipboard copy, and immediate navigation to Face Enrollment. |
| **Face Enrollment** | Enrol staff member's face using the phone's front camera. | **Google ML Kit Face Detection** + **MobileFaceNet Deep Learning (192-d embeddings)** with **16 KB memory page size compatibility** on Android 15+. |
| **Mark Attendance** | Front camera selfie capture, biometric match verification, location (Lat/Long), timestamp. Only record if face matches. | **Strict Server-Side & Local Cosine Verification** (`threshold: 0.75`). Face mismatch strictly rejects attendance creation. Added **Daily Status Card ("Marked Today ✓")** and **Multi-Punch (`+ Mark Another Entry`)** support. |
| **Attendance History** | Admin views staff profile with selfie, date, time, latitude, longitude. | Enhanced historical log view + **Embedded Interactive MapLibre GPS Map** pinpointing exact geographic coordinates. |
| **Network & Storage** | Local storage / any backend. | **Production Node.js REST API + MongoDB Atlas + Binary Multipart Streaming** with offline SQLite Room database caching. |
| **UX & Permissions** | Basic screens. | **Urushi Dark Theme with Kinpaku Gold & Patina Teal accents**, Edge-to-Edge window handling with `imePadding()`, and compulsory permission deep-linking. |

## 🏗 Architecture & System Design

The application strictly follows **Feature-Driven Clean Architecture** and the **MVVM + MVI Unidirectional Data Flow (UDF)** pattern:

```text
┌────────────────────────────────────────────────────────┐
│               Presentation Layer (UI)                  │
│   Jetpack Compose Screens • StateFlow • ViewModels     │
└───────────────────────────┬────────────────────────────┘
                            │ (Observes UI State / Triggers Intents)
┌───────────────────────────▼────────────────────────────┐
│                    Domain Layer                        │
│   UseCases • Domain Models • Repository Interfaces     │
└───────────────────────────┬────────────────────────────┘
                            │ (Executes Business Logic)
┌───────────────────────────▼────────────────────────────┐
│                     Data Layer                         │
│  Remote Data Sources (Ktor) • Local DAOs (Room DB)    │
│       Repository Implementations • Data Mappers        │
└────────────────────────────────────────────────────────┘
```


## 🛠 Technology Stack

### Android Client
* **Language**: Kotlin 2.0+ (Coroutines & StateFlow)
* **UI Toolkit**: 100% Jetpack Compose with Material 3 Design
* **Dependency Injection**: Dagger Hilt
* **Local Persistence**: Room SQLite Database (Offline-First Cache)
* **Networking**: Ktor Client 3.x with OkHttp Engine & Kotlinx Serialization
* **Image Loading**: Coil 3.x Compose
* **Camera**: CameraX (Front-camera capture with latency minimization)
* **Face Detection**: Google ML Kit Vision (`com.google.mlkit:face-detection`)
* **Face Recognition**: Google Play Services TFLite (`play-services-tflite-java`) running **MobileFaceNet** (192-dimensional vector extraction, 16 KB page-size compliant)
* **Location Services**: Google Play Services Location (`FusedLocationProviderClient`)
* **Mapping**: MapLibre Android SDK (Interactive dark cartographic maps)

### Backend Services
* **Runtime**: Node.js & Express.js REST API (`https://api.missioninvictus.com`)
* **Database**: MongoDB Atlas (Mongoose ODM)
* **Authentication**: JSON Web Tokens (JWT) with Bearer token authorization
* **Media Handling**: Multipart/form-data streaming with Cloud Image Storage

## 🤖 Biometric AI Verification Pipeline

```text
1. CameraX Front Capture
         ↓
2. Google ML Kit Face Detection  ──→ [Checks single face & extracts bounding box]
         ↓
3. Face Crop & Normalization     ──→ [Resizes to 112x112 RGB, normalizes pixels to [-1, 1]]
         ↓
4. MobileFaceNet (TFLite)        ──→ [Runs 192-dimensional deep neural feature extraction]
         ↓
5. Cosine Similarity Match       ──→ [Calculates Cosine Distance against Enrolled Face Vector]
         ↓
6. Backend Strict Verification   ──→ [If score >= 0.75 → HTTP 201 Created & Logged]
                                     [If score < 0.75  → HTTP 403 FACE_MISMATCH Rejected]
```

## 🚀 How to Run & Build

### Prerequisites
* **Android Studio**: Ladybug (2024.2.1+) or Koala
* **JDK**: Version 17 or higher
* **Android SDK**: API 35 (Android 15)
* **Physical Device / Emulator**: Android 8.0+ (API 26+) with front camera & GPS enabled.

### Build via Command Line
```bash
# 1. Clone the repository
git clone https://github.com/Mr-Ajay-Singh/Attendance-App.git
cd Attendance-App

# 2. Build Debug APK
./gradlew assembleDebug

# 3. Run Unit Tests (18 tests)
./gradlew test
```

The compiled APK will be located at:
`app/build/outputs/apk/debug/app-debug.apk`

## 🔒 Security & Privacy Guarantees

* **Zero Bogus Attendance**: Attendance records can never be created locally if the server face match fails or returns an error.
* **Token Isolation**: Staff members can only mark attendance for their own authenticated account.
* **Compulsory Permissions**: Explicit lifecycle management for Camera and Location permissions with automatic deep-links to App Permission Settings.
* **Android 15 16 KB Page Alignment**: Fully compliant with Google Play 2025 requirements via Google Play Services TFLite runtime.
